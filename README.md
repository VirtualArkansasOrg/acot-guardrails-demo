# acot-guardrails-demo

A demo repository for the ACOT 2026 session "Your Staff Are Already Building Apps with AI: A Governance Model That Works" (Kyle Yancey, Virtual Arkansas).

It shows five layers stopping the same key: CLAUDE.md, a Claude Code hook, gitleaks, GitHub push protection, and branch rules with required review. Every key that appears here is a canary token or the fake `ACOTDEMO-` format. Nothing in this repo is real: no real credentials, no student data, no staff names.

Want to use this in your own organization? Copy the starter template instead: https://github.com/VirtualArkansasOrg/ai-guardrails-starter
